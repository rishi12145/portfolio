# Personal Portfolio Website

A modern, responsive portfolio website showcasing my projects, skills, and professional journey. Built with a focus on clean design, smooth animations, and optimal user experience.

![Portfolio Preview](assets/images/portfolio-preview.png)

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works on desktop, tablet, and mobile devices
- **Dark/Light Theme**: Toggle between dark and light modes for comfortable viewing
- **Smooth Animations**: CSS animations and transitions for a modern feel
- **Dynamic Content**: 
  - Animated skill bars
  - Project filtering system
  - Animated counting statistics
  - Typing effect in hero section
- **Interactive Elements**:
  - Floating particles background
  - Smooth scrolling navigation
  - Project filtering
  - Form validation
- **Contact Form**: Functional contact form with EmailJS integration
- **Performance Optimized**: Fast loading times and smooth performance
- **Cross-Browser Compatible**: Works on all modern browsers

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Open index.html in your browser or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve
   ```

## 💻 Development

To modify the website:

1. **Styling**: Edit `css/style.css`
2. **Functionality**: Modify `js/main.js`
3. **Content**: Update `index.html`
4. **Assets**: Add/modify files in the `assets` directory

## 📱 Responsive Design

The website is responsive across multiple breakpoints:
- Desktop (1200px and above)
- Tablet (992px to 1199px)
- Mobile (768px and below)
