# Portfolio Website

A modern, responsive, and interactive portfolio website built with HTML, CSS, and JavaScript.

## Features

### UI/UX & Theme
- **Dark/Light Mode Toggle**: Switch between dark and light themes with a smooth transition
- **Color Palette Mixer**: Toggle between multiple accent colors (blue, purple, green, orange)
- **Modern Design**: Implemented with glassmorphism effects and clean aesthetics
- **Preloader Animation**: Cool loading spinner that displays while the site loads

### Animation & Effects
- **Scroll Animations**: Elements fade in as you scroll using Intersection Observer
- **Dynamic Typing Effect**: Rotating text in the hero section that cycles through different roles
- **Animated Counters**: Statistics that count up to their final value when scrolled into view
- **Floating Elements**: Parallax background particles that add depth to the hero section

### Smart Features
- **Form Validation**: Real-time validation on the contact form with error messages
- **Scroll Progress Bar**: Shows reading progress at the top of the page
- **Back to Top Button**: Smooth scroll back to the top of the page
- **Download Resume Button**: With animation on hover

### Responsive Design
- **Mobile-First Approach**: Fully responsive design that works on all devices
- **Sticky Navbar**: Navigation bar that shrinks and changes appearance on scroll
- **Hamburger Menu**: Animated mobile menu toggle for smaller screens

### Cool Extras
- **Project Filtering**: Filter projects by category (Web, UI/UX, Other)
- **Theme Customization**: Options to personalize the site's appearance
- **LocalStorage Support**: Remembers theme preferences between visits
- **Easter Egg**: Click the logo 5 times to activate a special animation

## Usage

1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content to make it your own

## Customization

### Personal Information
- Update text in `index.html` to reflect your information
- Replace placeholder images in the `assets` folder with your own
- Modify project details to showcase your work

### Theme Colors
- Edit CSS variables in `css/style.css` to change the color scheme
- Add additional color themes by following the existing pattern

### Skills & Projects
- Adjust skill percentages in the HTML
- Add or remove project cards to showcase your work
